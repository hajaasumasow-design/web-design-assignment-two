# Student Accommodation Finder

Plain HTML and CSS, no JavaScript. Open this folder in VS Code, then open index.html in a browser (or use the Live Server extension).

- index.html: Home
- about.html: About
- find-compare.html: Find & Compare
- services.html: Services
- contact.html: Contact
- style.css: all styles
- images/: photos

Listings, prices and providers are example content.
