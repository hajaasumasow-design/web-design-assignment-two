## Overview

Accommodation is an important part of student life. Students need a place to stay that is affordable, convenient, safe and close to their institution.

The **Student Accommodation Finder** brings accommodation information together in a single, simple website. Students can see the location, price, room type, facilities, photographs, availability and contact details of each option, then search and compare to find what suits them.

## Problem Statement

Students often struggle to find reliable accommodation information because it is scattered across friends, social media, adverts and landlords. This makes searching slow and comparing options difficult. Students also have different needs: some want low prices, others want to be close to campus or want certain facilities.

## Proposed Solution

A central website that organises accommodation listings and lets students search by **location**, **price range** and **accommodation type**, view full details, compare options and contact providers directly.

## Target Users

| User group | Need |
|---|---|
| New students | Learn what accommodation is available in the area |
| Budget-conscious students | Compare prices and find affordable rooms |
| Students who want to live near campus | Find places close to the university |
| Students comparing options | View several options before deciding |

## Features

- **Accommodation search (major feature):** filter by location, price range and accommodation type
- **Accommodation listings:** name, location, price, room type, facilities, photos and availability
- **Details page:** full information and a photo gallery for each accommodation
- **Compare options:** select up to 3 listings and view them side by side
- **Contact providers:** send an enquiry with a validated contact form
- **Clear navigation:** Home, About, Services, Accommodation and Contact pages
- **Responsive layout:** works on desktop, tablet and mobile `[confirm]`

## Website Structure

```
Home
├── About
├── Services
├── Accommodation
│   ├── Search & Results
│   ├── Accommodation Details
│   └── Compare Options
└── Contact
```

**User journey:** Home → Accommodation → Search → View details → Compare (optional) → Contact provider

## Design Process

This project follows the assignment deliverables:

1. **Project proposal:** background, problem, proposed solution and target users
2. **User research:** target users, user needs and user persona
3. **Information architecture:** sitemap, navigation structure and user journey
4. **Wireframes:** hand-drawn sketches and digital wireframes for Home, About, Services, Contact and the major feature (search)
5. **Figma interactive prototype:** clickable prototype of the full journey
6. **Website build:** the finished website, implemented from the approved design
